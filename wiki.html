🚀 快速上手

安装

前往 GitHub Releases 或下载页，选择与系统匹配的安装包。Windows 提供安装版与便携版，macOS 为 Universal dmg，Linux 提供 deb / AppImage / tar.gz。

首次启动

  • 应用启动后进入主页：快速操作、最近项目列表与时段问候语。
  • 在桌面设置中可选择浅色 / 深色 / 跟随系统主题、摄像头与麦克风、硬件加速等。
  • 素材库、扩展文档与打包器全部本地化，离线可用。

从源码构建

git clone --recursive https://github.com/Shiyuan-318/NeoWarp.git
cd NeoWarp
npm install              # 安装依赖（自动执行 patch-package 应用补丁）
npm run fetch            # 下载素材库、打包器与扩展资源
npm run webpack:compile  # 编译渲染进程
npm run electron:start   # 启动编辑器
npm run electron:build   # 打包安装程序
💡 提示：需要 Node.js 与 npm；docs/screenshots 为 git 子模块，克隆时请加 --recursive，否则请补执行 git submodule update --init。

🧭 界面导览

主页（Home）

应用启动页与调度中心：NeoWarp SOLO、新建项目 / 新建扩展、打开文件、图像编辑器、发起 / 加入协作等快速操作，以及最近项目列表。可在桌面设置中自定义主页 Logo、文字与背景图。

编辑器

完整保留 TurboWarp 的 JS / Wasm 编译器、深色模式、Addon 插件系统与 Packager 打包器（可打包 HTML / ZIP / EXE 等）。积木圆角半径可调、代码区 / 舞台区可自定义背景图。

AI 助手（NeoWarp AI）

独立窗口与编辑器深度联动，44 个内置工具：读取项目结构、增删改积木脚本、管理造型 / 声音 / 变量 / 列表、安装与热加载扩展、点击绿旗运行、舞台截图、联网搜索等。支持多模态（舞台截图 + 文件附件）、思维链展示、流式输出与用量统计。

NeoWarp SOLO

"纯 AI"工作台，没有传统编辑器界面：直接对 .sb3 或 JavaScript 扩展项目下达 AI 指令，由后台隐藏编辑器提供 VM 与工具支持；独立舞台弹窗提供绿旗 / 暂停 / 停止控制、变量监视器与"询问并等待"问答框；修改结果直接保存回原文件。

效率工具窗口

  • 待办清单：轻量待办事项，支持到点系统通知提醒。
  • 项目分析：积木分类占比环形图、复杂度 / 代码质量 / 健康度评估，可导出为图片。
  • 任务管理器：系统 CPU / 内存实时曲线与每个精灵的 CPU 占用排行。
  • 独立舞台：将舞台弹出为独立窗口（2x 缩放、输入回传），适合双屏演示与调试。

图像编辑器

Photoshop 风格分层图像编辑器：14 种工具、栅格 / 形状 / 文字 / 调整图层、16 种混合模式、非破坏性调整与破坏性滤镜、选区与自由变换，并支持把当前图片导出为已打开项目中角色的造型或新角色。

📁 文件格式

扩展名说明
.np1NeoWarp 项目（未压缩，默认保存格式）
.npnpNeoWarp 加密项目（AES-256-GCM + PBKDF2）
.viewsb3只读项目（加密，仅供查看，适合分享展示）
.sb3 / .sb2 / .sbScratch 1–3 项目
.jsNeoWarp 扩展（由扩展编辑器打开）

在编辑器中通过 文件 → 另存为 可选择保存格式；打开加密项目时需要输入密码。

🧠 AI 模型配置

NeoWarp 支持 OpenAI / Anthropic / Ollama / 自定义 API 格式，并预设 DeepSeek、智谱 GLM、Kimi、小米 MiMo、华为盘古、通义千问、SenseNova 等品牌。AI 助手 / SOLO / 扩展编辑器共享同一套模型配置，在桌面设置中统一管理。

🔒 隐私安全：API Key 仅保存在本地 tw_config.json，AI 请求经 tw-ai-proxy 主进程代理转发（绕过 CORS），不经过任何第三方服务器。

接入自定义模型

  1. 打开 桌面设置 → AI 模型；
  2. 选择 API 格式（OpenAI 兼容 / Anthropic / Ollama / 自定义）；
  3. 填入接口地址、API Key 与模型名称；
  4. 点击测试连接，成功后即可在 AI 助手与 SOLO 中选用。

👥 多人协作

发起 / 加入

一端作为主机开启房间（默认端口 8080，需设置房间密码），其他设备输入地址加入，也可自动扫描发现同一局域网内的房间。SHA-256 密码校验、心跳检测、认证超时与超大帧防护保障稳定连接。

权限控制

主机可为访客配置"添加扩展 / 删除扩展 / 删除精灵"等权限。

实时同步

任何一端的修改即时同步给所有人：代码改动实时呈现并避开拖拽 / 编辑字段时执行；监视器改动就地应用；远程更新期间的本地编辑不会被丢弃。内置 iOS 风格聊天区，协作沟通无需离开编辑器。

📱 手机编程

  • 扫码即连：AI 助手一键生成二维码，手机扫码后在浏览器中获得与桌面完全一致的 AI 聊天界面。
  • 桌面为唯一数据源：手机端的对话、流式输出与命令执行全部实时同步回桌面编辑器。
  • 手机预览：通过局域网（默认端口 8601）将当前项目导出为独立播放器，手机扫码即可试玩运行效果。

🧩 扩展开发

扩展编辑器

基于 Monaco（VS Code 同款内核）的多标签 JavaScript 编辑器，内置 NeoWarp 扩展模板。可一键"添加到项目"（注入到任意打开的编辑器窗口）或存入"我的扩展"库；右侧 AI 面板可弹出 / 停靠，帮你编写和调试 TurboWarp 扩展。

本地扩展库

把自定义扩展放进 Expands/ 目录，NeoWarp 通过 nw-expands:// 协议加载，扩展库会出现"NeoWarp"标签页（附带 Punycode 转换扩展示例）。

AI 工具链脚本

npm run ai:schema  # 从 scratch-blocks 生成积木 opcode schema
npm run ai:prompt  # 构建并写入 AI 系统提示词
npm run ai:check   # 校验 schema 与系统提示词是否为最新
npm run ai:test    # 运行 DSL 往返、数据工具与流式重试测试

❓ 常见问题

NeoWarp 与 TurboWarp 是什么关系？
NeoWarp 基于 TurboWarp Desktop 二次开发，完整继承其 JS / Wasm 编译器、扩展生态、Addon 插件、Packager 与深色模式等能力，并在此之上增强了 AI 辅助创作、多人协作、工作流与视觉体验。请遵守上游的许可协议（GPL-3.0）。
离线可以使用吗？
可以。素材库（tw-library）、扩展文档、打包器与扩展画廊全部本地化内置，离线可用。仅 AI 联网搜索、更新检查等少数功能需要网络。
AI 的 API Key 安全吗？
API Key 仅保存在本地 tw_config.json，AI 请求经主进程 tw-ai-proxy 代理转发，密钥不出本机、不经过第三方服务器。
协作需要公网服务器吗？
不需要。协作由主机端直接开启房间（默认端口 8080），同一局域网内的设备可自动扫描发现；跨网段时需保证设备间网络可达。
如何加快捷键 / 修改界面？
在桌面设置中可调整主题、摄像头与麦克风、硬件加速、后台节流、绕过 CORS、拼写检查等；编辑器的积木圆角半径、代码区 / 舞台区背景图等视觉项也可在设置与 Addon 中自定义。

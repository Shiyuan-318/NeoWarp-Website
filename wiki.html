NeoWarp 使用文档

从安装到进阶：AI 助手、SOLO、协作与移动端、内置工作室、文件格式与加密，都在这一页。

关于 NeoWarp

NeoWarp 是一款使用 Electron 构建的离线 Scratch 3 编辑器，基于 TurboWarp Desktop 二次开发。它完整继承了 TurboWarp 的 JS / Wasm 编译器、扩展生态、Addon 插件系统、Packager 打包器与深色模式，并在此基础上加入 AI 辅助创作、多人协作、手机编程与一整套内置创作工具。

适合谁用：需要离线编写与运行 Scratch 项目的用户；希望用 AI 辅助写积木的创作者；需要多设备、多人协同的课堂与小组；以及对编辑器视觉与工作流有更高要求的使用者。

核心特性

  • NeoWarp AI — 44 项内置工具，可读写项目结构、增删改积木、管理素材、安装扩展、运行与截图。
  • NeoWarp SOLO — 纯 AI 工作台，不开编辑器界面也能完成项目编写。
  • 多人协作 — 主机开房间，局域网自动发现，实时同步与内置聊天。
  • 手机编程 — 扫码在手机浏览器中继续对话，桌面为唯一数据源。
  • 扩展编辑器 — 基于 Monaco 的 JavaScript 编辑器，可直接写 TurboWarp 扩展。
  • 图像编辑器 — 分层图像编辑器，含选区、调整、滤镜与混合模式。
  • 效率工具 — 待办清单、项目分析、任务管理器、分离舞台与数据预览。
  • 格式与安全 — .np1 / .npnp / .viewsb3 三种自家格式，加密与只读分享。

与 TurboWarp 的关系

NeoWarp 是 TurboWarp Desktop 的下游分支，不是替代品。上游能力被完整保留，NeoWarp 只在其上做增量增强，因此 TurboWarp 的项目、扩展与插件在 NeoWarp 中都能正常使用。

能力TurboWarp DesktopNeoWarp
AI 编程助手无44 项工具 + 积木 DSL
协作与手机编程无局域网房间 + 扫码
扩展 / 图像编辑器无内置两个独立编辑器
工程格式.sb3另加 .np1 / .npnp / .viewsb3
编译器与打包器有完整保留

系统要求

NeoWarp 基于 Electron 41 构建，2.0.0 起新增 macOS 与 Windows ARM 支持。

平台版本架构
WindowsWindows 10 及以上x64 / arm64
macOSApple 芯片机型arm64
LinuxDebian / Ubuntu 及兼容发行版x86_64
Android安装包（APK）通用
从源码构建：需要 Node.js 与 npm。依次执行 npm install、npm run fetch、npm run webpack:compile，再用 npm run electron:start 启动。

下载与安装

安装包由 GitHub Releases 提供，也可以在下载页按平台挑选。

  • Windows — 安装版双击运行并可自选路径；便携版解压即用，不写注册表。
  • macOS — 打开 .dmg 后拖入「应用程序」。首次运行若被拦截，在「隐私与安全性」中允许打开。
  • Linux — .deb 用 sudo dpkg -i 安装；AppImage 加执行权限后直接运行。
  • Android — 安装 APK 时需允许「安装未知来源应用」。

首次启动

新安装或跨大版本升级后，会先出现一次引导：选择语言、选择深色 / 浅色模式、配置 API Key，每一步都可以确认或跳过。

引导结束后进入主页（Home）——它是应用的启动页与调度中心，集中了全部功能入口：NeoWarp SOLO、新建项目、新建扩展、打开文件、图像编辑器、发起 / 加入协作，以及最近项目列表。主页的 Logo、文案与背景图都可以在桌面设置里自定义。

创建新项目

在主页点击「新建项目」，或在编辑器菜单栏选择「文件 → 新建」。新项目包含一个舞台和一个默认角色，可以直接开始拖拽积木。

打开工程文件

支持三种方式打开：菜单栏「文件 → 打开」选择文件；把文件直接拖进 NeoWarp 窗口；或在文件管理器中双击已关联的工程文件。

注意：打开 .npnp 加密工程时会弹出密码输入框，需要输入正确密码才能解密。

保存工程

  • 默认保存 — 保存为 .np1 未压缩工程，便于版本控制与差异比较。
  • 另存为 — 自定义文件名与位置，也可另存为 .sb3 与 Scratch 生态互通。
  • 加密保存 — 另存为 .npnp，需要设置标题与密码。
  • 只读分享 — 导出 .viewsb3，接收方只能观看舞台。

快捷键 Ctrl+S / Cmd+S 保存，Ctrl+Shift+S 另存为。

配置模型

从主页或菜单栏打开「AI 助手」，点击右上角设置图标添加模型。NeoWarp 兼容 OpenAI、Anthropic、Ollama 与自定义 API 格式，并内置常见厂商预设。

  • 填入 API 地址、API Key 与模型名称即可。
  • AI 助手、SOLO 与扩展编辑器共享同一套模型配置，在桌面设置中统一管理。
  • 对话区顶部的状态点变绿，表示当前模型的 Key 已配置完成。
隐私：API Key 只保存在本机 tw_config.json；AI 请求由主进程代理转发，不经过第三方服务器。

对话与流式输出

  • 在底部输入框输入需求，Enter 发送，Shift+Enter 换行。
  • 回答以流式方式实时输出，支持思维链展示与思考强度调节。
  • 左侧对话列表可管理多个会话，随时切换或新建。
  • 底部可附加图片与 .md、.txt、.pdf、.csv 文件，也可以把舞台截图发给模型。
  • 顶部可查看用量统计，并一键切换模型。

工具调用与积木 DSL

AI 助手不只是聊天，它通过 44 项内置工具直接操作项目。核心机制是一套自研的积木 DSL：AI 用「opcode + 参数」的文本形式描述脚本，经编辑器的 opcode schema 校验后才写入工作区。

能做什么

  • 读取项目结构与指定角色的积木、变量、列表。
  • 新增、插入、修改输入、删除积木，修改精确落到单个积木。
  • 管理造型、声音、变量与列表，从 URL 添加素材。
  • 安装并热加载自定义扩展，点击绿旗运行，截取舞台画面。
  • 联网搜索（聚合 DuckDuckGo、Bing、Wikipedia）以查阅资料。
提示：工具调用有超时限制，涉及大量数据的操作需要等待。使用任何 AI 功能前请先备份项目。

撤销 AI 修改

每次 AI 改动之前，NeoWarp 都会自动保存一份项目快照。如果结果不符合预期，可以一键恢复到本次对话之前的状态，不必手动逐条撤回积木。

什么是 SOLO

NeoWarp SOLO 是一个「纯 AI」工作台：没有传统编辑器界面，你直接对项目下达指令，由后台的隐藏编辑器提供 VM 与工具支持。适合批量改写、维护旧工程，或只想用对话完成一个项目的场景。

使用 SOLO

  • 从主页进入 SOLO，选择一个 .sb3 或 JavaScript 扩展项目。
  • 用自然语言描述要做的修改，AI 完成后把结果直接保存回原文件。
  • 独立舞台弹窗提供绿旗、暂停、停止控制与变量监视器。
  • 项目里的「询问并等待」会在弹窗中提示，可直接作答。

发起房间

在主页选择「发起协作」，设置房间密码后开启房间。默认端口为 8080，请确保防火墙允许局域网访问该端口。

加入房间

其他设备选择「加入协作」，输入主机地址与房间密码即可；同一局域网内的房间也可以被自动扫描发现，直接点选即可，不用手动抄写地址。

权限与聊天

  • 主机可为访客分别配置「添加扩展 / 删除扩展 / 删除精灵」权限。
  • 内置 iOS 风格聊天区，沟通不必离开编辑器。
  • 任何一端的修改都会即时同步给房间内所有人。
  • 连接使用 SHA-256 密码校验，并带心跳检测、认证超时与超大帧防护。

扫码连接

在 AI 助手中一键生成二维码，手机扫码后在浏览器里打开与桌面完全一致的 AI 聊天界面，无需安装任何 App。桌面是唯一数据源，手机端的对话、流式输出与命令执行全部实时同步回桌面编辑器。

手机预览

手机预览会通过局域网（默认端口 8601）把当前项目导出为独立播放器，手机扫码即可试玩运行效果，适合快速验证触屏交互。

编写扩展

扩展编辑器是一个基于 Monaco（VS Code 同款内核）的多标签 JavaScript 编辑器，内置 NeoWarp 扩展模板。

  • 新建或打开 .js 扩展文件，多标签并行编辑。
  • 「添加到项目」可把扩展注入到任意打开的编辑器窗口。
  • 也可以存进「我的扩展」库，之后重复使用。

扩展编辑器中的 AI

右侧 AI 面板可以弹出或停靠，帮你编写与调试 TurboWarp 扩展。它与 AI 助手共享模型配置，因此不必重复填写 Key。

工具与选区

图像编辑器是一个独立窗口，采用菜单栏、工具选项栏与状态栏三段式布局。左侧提供 14 种工具：移动、矩形选框、套索、魔棒、裁剪、吸管、画笔、橡皮擦、油漆桶、渐变、文字、形状、缩放与抓手。

  • 矩形选框、套索与魔棒用于建立选区，支持加选、减选与反选。
  • 选区可设置羽化，并以蚂蚁线动画显示边界。
  • 自由变换支持缩放与旋转；另有图像大小、画布大小、旋转 90°/180° 与水平 / 垂直翻转。

图层

  • 图层类型包含栅格、形状、文字与调整图层。
  • 支持 16 种混合模式、不透明度、可见性与锁定。
  • 可新建、复制、删除、栅格化、向下合并与重新排列，双击缩略图可重命名。

调整与滤镜

  • 非破坏性调整 — 亮度、对比度、饱和度、色相、模糊、去色、棕褐与反相，随时可改可删。
  • 破坏性滤镜 — 高斯模糊、锐化、马赛克、杂色、浮雕、查找边缘、阈值、色调分离、棕褐与黑白。
  • 右侧面板还提供颜色取色器（HSV + HEX / RGB）与色板、属性面板，以及带步骤名、可点击回退的历史记录。

导入与导出

可打开与导出 PNG、JPG 与 WebP。桌面版经系统文件对话框读写，网页版使用文件系统 API 或下载。

待办清单

一个轻量待办窗口，在创作过程中随时记录任务与灵感。

  • 顶部输入框添加待办，Enter 或点「添加」即可，新项出现在列表顶部。
  • 双击文字进入编辑，Enter 保存、Esc 取消；清空内容保存会自动删除该项。
  • 点击左侧圆形复选框标记完成，已完成项显示删除线；底部可一键清除已完成项。
  • 可设置到点系统通知提醒。
  • 数据保存在本地，键名为 neowarp_todo_list，不会同步到云端。

项目分析

以环形图展示积木分类占比，并给出复杂度、代码质量与健康度评估。分析结果可导出为图片，适合做作品说明或教学材料。

任务管理器

  • 顶部卡片显示系统 CPU 占用率与核心数、已用与总内存。
  • 折线图展示最近约 90 秒的 CPU 与内存趋势。
  • 下方按角色列出线程数、CPU 占用（带进度条）、内存估算、积木数与造型数，点击列标题可排序。
  • CPU 进度条随占用率变色：正常为青色，中等为黄色，较高为红色。

分离舞台与数据预览

分离舞台把舞台弹出为独立窗口，2 倍缩放并回传输入，适合双屏演示与调试，通过 tw-detached-stage 协议加载。数据预览则以小窗口呈现项目产生的 data: URL 内容，方便排查数据类积木。

编辑器外观

  • 积木圆角半径可调，运行时即时生效；扩展勾选框改为圆形。
  • 代码区与舞台区支持自定义背景图。
  • 「无限画布绘制」解除画图编辑器的画布尺寸限制。
  • 素材库支持固定（置顶）与右键菜单。
  • 主页、AI 助手、待办清单、任务管理器等界面采用毛玻璃质感与过渡动画。
  • 主题可选浅色、深色或跟随系统。

画图编辑器增强

在 Scratch 自带画图编辑器的基础上，新增智能对齐参考线，以及箭头、双箭头、心形、梯形、三角形等形状工具；圆角矩形的圆角与曲率可调。

.np1 未压缩工程

.np1 是 NeoWarp 的原生工程格式，也是默认保存格式。与 .sb3 的 ZIP 压缩不同，它以未压缩方式存储项目数据，便于版本控制与差异比较。

  • 扩展名：.np1，MIME 类型 application/x.scratch.np1。
  • 安装后自动关联，双击即用 NeoWarp 打开。

.npnp 加密工程

.npnp 为加密工程格式，使用 AES-256-GCM 配合 PBKDF2 派生密钥，打开时需要输入密码。详见加密保存。

.viewsb3 只读分享

.viewsb3 专为分享成品而设计：对方打开后只能看到全屏舞台，无法查看或编辑任何积木代码，从而保护创作思路。

版本要求：需要 NeoWarp 1.0.11 及以上版本才能正确打开。若用旧版本或其他 Scratch 编辑器打开，可能无法正确显示。

扩展名说明MIME 类型

加密保存

选择「加密保存」后填写三项内容：

  1. 标题 — 项目标题，不能为空。
  2. 密码 — 加密密码，不能为空。
  3. 确认密码 — 再次输入，两次必须一致。
重要：请务必记住密码。密码一旦遗忘，加密工程将无法恢复，建议另行妥善保管。

打开加密文件

打开 .npnp 时会自动弹出密码框：输入后回车即可；密码错误会重新提示；Esc 或取消可放弃打开。解密在主进程中完成，密码不会明文驻留内存。

架构与权限

编辑器、主页、AI 助手、协作、SOLO 等二十余种窗口全部通过 tw-* 自定义协议加载，与主进程解耦。本地素材库（tw-library）与扩展画廊（tw-extensions）以 Brotli 压缩内置，离线可用。

全进程启用 Electron 沙箱，禁用 webview；剪贴板、通知等敏感权限按窗口逐项审批。

密钥与网络

API Key 仅保存在本地 tw_config.json。AI 请求通过 tw-ai-proxy 由主进程代理转发以绕过跨域限制，密钥不出本机，也不经过任何第三方中转服务器。

编译器与扩展

完整保留 TurboWarp 的 JS / Wasm 编译器与全部官方扩展。素材库、扩展文档与打包器均已本地化，断网也能使用。

Addon 插件

通过菜单栏的 Addons 入口管理插件：启用 / 禁用插件、调整插件设置、浏览可用列表。插件经 tw-editor 协议加载，与编辑器主体隔离运行。

Packager 打包器

离线内置的打包器可把项目导出为可分发格式：单文件 HTML、ZIP 压缩包，以及 Windows / macOS / Linux 可执行文件。打包后的作品可脱离 NeoWarp 独立运行，适合分享给没有安装 NeoWarp 的人。

本地扩展库

放在安装目录 Expands/ 下的自定义扩展，会通过 nw-expands:// 协议加载，并出现在扩展库的「NeoWarp」标签页中（附带 Punycode 转换扩展示例）。

常见问题

忘记加密密码怎么办？

无法找回。.npnp 的加密不可逆，请从其他副本或备份恢复。保存密码时建议使用密码管理器。

AI 修改把项目改坏了怎么办？

使用「撤销 AI 修改」恢复到本次对话之前。NeoWarp 在每次改动前都会自动保存快照，但仍建议对重要工程另存副本。

协作连不上主机？

确认两端在同一局域网，主机防火墙放行 8080 端口，并核对房间密码。也可以尝试用自动扫描发现房间。

能把 NeoWarp 当成 Scratch 用吗？

可以。NeoWarp 完整支持 .sb3、.sb2 与 .sb，编译器、扩展与 Addon 能力与 TurboWarp 一致。

Mac 上提示应用已损坏？

这是 Gatekeeper 对未签名应用的限制。在「系统设置 → 隐私与安全性」中允许打开，或右键应用选择「打开」。

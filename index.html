AI 创作

让 AI 直接改积木，而不只是陪你聊天

助手通过 44 项内置工具读写你的项目：读结构、增删改脚本、管理造型与声音、装扩展、点绿旗、截图看运行效果。

NeoWarp AI 助手

AI 用一套自研的积木 DSL 描述脚本，经编辑器的 opcode schema 校验后才写入工作区。修改会精确落到具体积木，而不是覆盖整个项目。

  • 44 项工具覆盖积木、造型、声音、变量、列表与扩展管理
  • 增量修改支持新增、插入、改输入、删除，粒度到单个积木
  • 一键撤销每次改动前自动存快照，随时回到对话前的状态
  • 看得见结果把舞台截图发给模型，让它自己检查运行效果

多模态输入

可发送舞台截图，也能附加 .md、.txt、.pdf、.csv 文件，让模型带着上下文作答。

内置联网搜索

聚合 DuckDuckGo、Bing 与 Wikipedia，需要查资料时不必切出编辑器。

从 URL 加素材

粘贴图片地址即可添加造型或精灵，支持本地路径、全角标点纠正与魔数格式识别。

待办联动

复杂任务自动拆成步骤卡片，执行进度实时更新，长任务不再半途失联。

NeoWarp SOLO

一个纯 AI 工作台，没有传统编辑器界面。直接对 .sb3 或 JavaScript 扩展项目下达指令，后台的隐藏编辑器负责提供 VM 与工具支持，改完直接写回原文件。

  • 独立舞台弹窗：绿旗、暂停、停止与变量监视器
  • 支持项目里的「询问并等待」，可以在弹窗里直接作答
  • 改动结果保存回原文件，适合批量改写与维护旧工程
模型接入

兼容 OpenAI、Anthropic、Ollama 与自定义 API 格式，内置主流厂商预设。密钥只保存在本机 tw_config.json，请求经主进程代理转发，不经过第三方服务器。

协作与移动

同一个工程，多台设备一起写

一端开房间，其他设备扫码或输入地址加入，改动实时同步。手机也能给项目下发积木指令。

多人协作

主机开启房间（默认端口 8080，需设置房间密码），其他设备加入即可共同编辑。同一局域网内的房间可以被自动扫描发现，不用手动抄地址。

  • 权限控制可分别为访客开关「添加扩展 / 删除扩展 / 删除精灵」
  • 实时聊天内置 iOS 风格聊天区，沟通不必离开编辑器
  • 稳定连接SHA-256 密码校验、心跳检测、认证超时与超大帧防护

任何一端的修改都会即时同步给房间内所有人。

手机编程

AI 助手一键生成二维码，手机扫码后在浏览器里得到与桌面完全一致的对话界面。手机端不存数据，桌面是唯一数据源，对话与执行结果全部实时同步回编辑器。

  • 扫码即连，无需安装任何 App
  • 手机预览：通过局域网（默认端口 8601）导出独立播放器，扫码即可试玩
手机端

躺着也能写项目：手机上发出指令，桌面编辑器里积木跟着变。适合临时改一处、课堂上多人轮流操作。

内置工作室

编辑器之外，工具也已经装好了

写扩展、改图片、盯性能、记待办，都不用再去找第三方软件。

扩展编辑器

基于 Monaco（VS Code 同款内核）的多标签 JavaScript 编辑器，内置 NeoWarp 扩展模板。写完可一键注入到任意打开的编辑器窗口，或存进「我的扩展」库。

  • 多标签编辑、语法高亮与内置模板
  • 右侧 AI 面板可弹出或停靠，帮你编写与调试 TurboWarp 扩展
  • .js 文件已关联到 NeoWarp，双击即用扩展编辑器打开

图像编辑器

一个 Photoshop 风格的分层图像编辑器，独立窗口运行：菜单栏、工具选项栏与状态栏三段式布局，左侧 14 种工具，右侧是颜色、图层、历史、调整、滤镜与属性面板。

  • 图层栅格 / 形状 / 文字 / 调整图层，16 种混合模式与不透明度
  • 选区与变换矩形选框、套索、魔棒，支持加选减选反选与羽化
  • 调整与滤镜非破坏性调整叠加高斯模糊、锐化、马赛克等破坏性滤镜
  • 可撤销到任意步骤的历史记录，导入导出 PNG / JPG / WebP

JS / Wasm 编译器

桌面集成

文件与安全

三种自家格式，加上完整的 Scratch 兼容

安装后这些扩展名会自动关联到 NeoWarp，双击即可打开；也可以在系统里手动改回其他编辑器。

工程文件格式
扩展名说明用途
.np1NeoWarp 未压缩工程默认保存格式，便于版本控制与差异比较
.npnpNeoWarp 加密工程AES-256-GCM + PBKDF2 密码加密，打开需输入密码
.viewsb3NeoWarp 只读分享格式对方只能看到全屏舞台，无法查看或编辑源码
.sb3Scratch 3 工程标准压缩格式，可与 Scratch 生态互通
.sb2 .sbScratch 2 / 1 工程打开旧工程，自动迁移到当前格式
.jsNeoWarp 扩展双击由扩展编辑器打开

密码保护作品

保存时设置标题与密码（含二次确认），打开时校验后解密；密码错误会重新提示。忘记密码无法找回，请妥善保管。

只读分享

导出 .viewsb3 后，对方打开只看到全屏舞台，源码与积木全部隐藏。建议对方使用 NeoWarp 1.0.11 及以上版本。

架构与安全

二十余种窗口全部经 tw-* 自定义协议加载，与主进程解耦；全进程启用沙箱、禁用 webview，剪贴板与通知等权限逐窗口审批。

密钥不出本机

API Key 只写入本地 tw_config.json；AI 请求由主进程代理转发以绕过跨域限制，不经过任何第三方中转服务器。
